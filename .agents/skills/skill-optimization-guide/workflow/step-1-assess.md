# 步骤 1：评估现状

## 输入

目标 skill 的所有文件（SKILL.md、workflow/、references/、script/、assets/）。

## 操作

逐文件阅读，记录以下问题：

1. **统计行数**：SKILL.md 超过 300 行标记为"胖"。
2. **标记重复**：同一条规则或同一段代码出现在两个以上文件里，记录位置。
3. **标记抽象词**：找出胶水、赋能、闭环、中台、一体化、高级等无法直接执行的词。
4. **标记反向表达**：找出以"不要/禁止/避免"开头但不涉及高风险的句子。
5. **核对规则数**：入口声称的规则数 vs 详细文件里实际展开的规则数，是否一致。
6. **检查相关文件列表**：references/ 下每个文件是否都出现在 SKILL.md 的相关文件列表里。

## 产出

一份问题清单，格式如下：

```markdown
## 问题清单

### 胖文件
- SKILL.md：XXX 行（建议 ≤ 300 行）

### 重复内容
- "规则 A 描述" 出现在 SKILL.md 第 X 行 和 references/xxx.md 第 Y 行

### 抽象词
- "胶水"出现在 SKILL.md 第 X 行
- "赋能"出现在 references/xxx.md 第 Y 行

### 反向表达（非高风险）
- "不要在 PC 端使用 window.open" → 改为正向写法

### 规则数不一致
- 入口写 17 条，实际展开 18 条

### 相关文件列表缺失
- references/xxx.md 未出现在相关文件列表中
```

- [ ] 重复内容标记完成
- [ ] 抽象词标记完成
- [ ] 规则数核对完成
