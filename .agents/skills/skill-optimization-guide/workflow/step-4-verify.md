# 步骤 4：验证收尾

## 输入

步骤 3 产出的全部改写后文件。

## 操作

按以下顺序逐项验证：

### 4.1 结构验证

- [ ] SKILL.md 行数建议 ≤ 300
- [ ] 每个 workflow 文件有完整的 输入/操作/产出/Checklist 四部分
- [ ] 相关文件列表列出了 references/ 下所有文件
- [ ] 所有相对路径链接实际可达（用工具检查文件是否存在）

### 4.2 重复验证

对比任意两个文件：
- [ ] 同一条规则没有在两个文件里都详细解释
- [ ] 同一段代码没有出现在两个文件里
- [ ] 内容重叠率 ≤ 8%

### 4.3 语言验证

逐文件扫描：
- [ ] 无抽象词：胶水、赋能、闭环、中台、一体化、高级
- [ ] 无过程词：考虑、感觉、为什么、后续、可以再、讨论、方案、临时、暂时
- [ ] 无冗余负向句（非高风险场景的"不要/禁止/避免"）
- [ ] 每句话格式为"对象 + 动作 + 产物"或"条件 → 动作"

### 4.4 一致性验证

- [ ] SKILL.md 核心规则的条数 = references 中展开的条数
- [ ] SKILL.md 流程表的步骤数 = workflow/ 下的文件数
- [ ] 完成标准中每一项都能通过客观检查（有数字或可验证条件）

## 产出

验证报告，列出：
- 通过项（打勾）
- 未通过项 + 具体位置 + 修复建议

如果有未通过项，回到步骤 3 修复后重新验证。

## Checklist

- [ ] 结构验证全部通过
- [ ] 重复验证全部通过
- [ ] 语言验证全部通过
- [ ] 一致性验证全部通过
- [ ] 验证报告已输出
