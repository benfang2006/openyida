# 工作台入口模式

## 高频入口优先

入口按使用频率和角色任务排序，不按创建时间或表单类型排序。

先分清入口目标：同应用内页面优先在平台应用导航内切换，不作为工作台内容区快捷入口；内容区入口优先承载当前页动作、表单新建/查看、外部链接、跨应用资源。只有用户显式要求隐藏平台导航并做页面内导航壳时，同应用页面切换才进入页面内导航。

| 分组 | 示例 |
| --- | --- |
| 我要处理 | 待办审批、异常处理、今日巡店 |
| 我要发起 | 新建申请、提交数据、导入记录 |
| 我要查看 | 进度查询、报表、历史记录 |
| 配置维护 | 基础数据、权限、规则 |

## 视觉规则

- 主入口可以更大，其余入口保持紧凑。
- 图标是功能标识，不是装饰。
- 长尾入口折叠或放到次级区域。
